Sattva Index Flows

There is no interface yet. This build is the data layer only. This page is a placeholder so that python3 -m http.server 8080 -d public serves something honest rather than a directory listing; it deliberately shows no figures, because showing a plausible placeholder number would be worse than showing none.

Data currently published here

  • data/companies.json — the join, and the only file the interface should read: one record per company, with its free-float factor, which exchange published it, and which funds hold it. A null under a fund means not held, never a zero weight.
  • data/msci-funds.json — the India equity slice of three iShares ETFs, from BlackRock's own fund-holdings workbooks. Every weight is a percentage of the single fund it appears under.
  • data/nse-freefloat.json — free-float market cap as published by NSE's pre-open API. Not computed from promoter holding.
  • data/bse-freefloat.json — free float and full market cap from BSE, for every company the funds hold plus every scrip above the desk's ₹2,000 Cr floor. All figures in rupees; BSE publishes ₹ crore.
  • data/bse-scrip-master.json — the active listed equity universe.
  • data/nse-universe.json — the NSE symbol ↔ ISIN bridge.
